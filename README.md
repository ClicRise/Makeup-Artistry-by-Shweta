# Makeup Artistry by Shweta

This project was built with [Lovable](https://lovable.dev) and is deployed to [GitHub Pages](https://clicrise.github.io/Makeup-Artistry-by-Shweta/).

## Develop locally

Requires [Bun](https://bun.sh/).

```sh
bun install
bun run dev
```

Pushing to `main` builds the static site and deploys it to GitHub Pages through `.github/workflows/pages.yml`.

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
