# Makeup Artistry by Shweta

This project was built with [Lovable](https://lovable.dev) and is deployed to [GitHub Pages](https://clicrise.github.io/Makeup-Artistry-by-Shweta/).

## Develop locally

Requires [Bun](https://bun.sh/).

```sh
bun install
bun run dev
```

Before the first deployment, open **Settings → Pages** in the GitHub repository and set **Build and deployment → Source** to **GitHub Actions**. Pushing to `main` then builds the static site and deploys it through `.github/workflows/pages.yml`.

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
